# Hyperframes workspace

Hyperframes is the motion-graphics specialist layer. It should generate cards, data callouts, maps, kinetic titles, web/product segments and reusable visual clips which are then composited by Remotion.

Initial setup on the production machine:

```bash
npx skills add heygen-com/hyperframes --full-depth
npx hyperframes doctor
```

The first target here is a DGBN animated news-card component matching the fields in `jobs/samples/dgbn-2026-08-05-evening.json`.
